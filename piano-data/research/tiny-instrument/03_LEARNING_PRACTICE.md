# Learning, practice and theory engine

Sources: Swift type metadata (exact names), `__cstring` strings (exact), the leaked code graph (file names). Lesson prose is copyrighted content: only structure and ids are given.

## 1. App modes and navigation (exact)
- `AppMode` = lesson, earTraining, practice, playback, compose (the five top-level modes; colour tokens learn / listen / practice / playback / compose, see 04).
- `SidebarView` = music, songs, instruments, theory, compose, scale, scaleDegrees, chords, earTraining, progressions, songbook.
- `MainView` = content, settings, debug, instrumentPicker. `ViewMode` = grandStaff, guitar, instrument.
- `ModePickerAction` = mode, lesson, earTrainingLevel, practice, randomScale, randomChord, newComposition, newProgression, importSong.
- `CurriculumSectionHeader` (Learn list sections) = courses, introduction, appLessons, playExplore, reading.

## 2. Learn: chapters, lessons, steps
`TheoryChapter {id: Int, title, subtitle, lessons: [TheoryLesson], prerequisiteChapterId?, tier: ChapterTier, requiredPack: ContentPack?, introducedInVersion?}`.
`ChapterTier` = introduction, fundamentals, core, intermediate, advanced, expert, composition, app, concept, reading.
`TheoryLesson {id, stableId, title, subtitle?, steps: [LessonStep], summaryPoints, crossReference?, ariaPresets: [String], lessonDescription?, accentMode?}`. Chapters unlock by completing gating lessons (help string, exact). Chapter unlock triggers a celebration (02 §8).

`LessonStep` (26 kinds, exact): context(text, note?, tip?), discover(actions), name(explanation, explanationList, highlights, showsKeyboard, keyboardGuide?), exercise(Exercise), staffPlay(prompt, notes), readStaff(prompt, figure, calloutIndex?, keySignature?), rhythmTap(prompt, figure, bpm), scalePattern(prompt, scale, demoTonics, picker), drill(Drill), prePlayRoutine(PrePlayRoutine), piece(PieceStep), transfer(TransferChallenge), listenExample(text, notes, noteDuration), playModeCompare(prompt, chord, modes), voicingCompare(prompt, chord, voicings), keyTransposeCompare(prompt, romanNumerals, variants), compose(exercise), freeplay(allowedPitchClasses, dronedKeys, prompt), chordChartAnatomy, progressionExample, songbookImportDemo, songPracticeSetupTour, songPracticeViewTour, conceptLink(stableId, label), tryMode(mode, practicePrefill?), summary.

`Exercise` (5 kinds): play(prompt, expectedNotes, hints, expectedGroups?, displayInstrument?, registerMatters), multipleChoice(question, options, correctIndex, explanation, showsKeyboard, hintNotes?), identify(staffNotes, question, options, correctIndex), connect(prompt, steps), staffRecognition(question, options, correctIndex, explanation). `registerMatters` decides octave-sensitive vs pitch-class checking.

Other step types: `Drill {title, steps, positions, hand: right/left/both, articulation?, dynamics?, handPlacement?}`; `PrePlayRoutine.Item = tapRhythm(figure, bpm) | sayInOrder(kind: letterNames/fingerNumbers/counts, chips)`; `TransferChallenge {prompt, source: piece(songId)/drill, variation}`; `PieceRender = preStaff | staff`.

Rich text: lesson strings use inline tokens `[type:value]` parsed by `MusicTextParser` into `MusicToken = plain | tagged(MusicTokenType, String)`. 45 token types (exact): note, rn, interval, chord, key, scale, mode, appMode, feature, ui, color, degree, tempo, timesig, rhythm, dynamic, measure, tip, root, cadence, clef, accidental, song, midi, lhand, rhand, drone, finger, motif, lesson, playExplore, instrument, pattern, duration, symbol, articulation, ornament, voicing, navigation, pedal, glissando, playMode, nonChordTone, function. Tokens are tappable (play the note/chord/rhythm, open settings, navigate to lesson). Example from strings: `[note:C4]`, `[interval:M3]`, `[rhythm:dotted-half]`, `[tempo:120]`, `[cadence:deceptive]`, `[PLAY_EXPLORE:…]`.

## 3. Courses (multi-day plans, newest feature)

Strings: "Play a clean run to complete", "Complete & return to course".

## 7. Practice (Scales, Chords, Progressions, MIDI songs, Songbook)
- Game modes for every practice type: `chaseTheNotes` (wait-mode: next note lights, waits) and `fallingNotes` (scrolling note highway on `FallingNotesCanvas`).
- `StrictnessMode` = always, guided, strict. `PlaybackMode` = stepped, continuous. `NoteStatus` = upcoming, active, hit, missed.
- Falling-notes tuning: `PracticeHoldTimeOption` tap/short/medium/long (+ randomize), `PracticeNoteSpacingOption` compact/standard/relaxed/wide, `PracticeNoteOverlapOption` none/slight/medium/generous, `CanvasDisplayMode` fixedHeight/proportional, `RevealLevel` both/numeralOnly/nameOnly (for progressions).
- Chords: `PracticeContentMode` singleChord / progression / songbook; built-in `ChordProgression` = allTriads, I_IV_V_I, I_V_vi_IV, I_vi_IV_V, ii_V_I, I_IV_vi_V; `PlayMode` (10): block, arpeggioUp, arpeggioDown, strum, random, upDown, downUp, outsideIn, alberti, skip; `HandConfigMode` none/droneLeft/chordSplit; `DroneInterval` root/fifth/octaveBelow; inversions per chord; `VoicingStyle` block/spread/arpeggio.
- Scales: `ScalePracticeLaunch` (scale, root, pattern, octaveCount, startingOctave, strictness, holdTime…); practice hand setting.
- MIDI songs: `MIDIHandConfig = splitByNote(splitNote) | byTrack(leftTracks, rightTracks) | merged`; setup steps handAssignment → settings; speed multiplier; loop; `MultiHandSessionManager` (two-hand drills: bpm, workingBPM, completedReps, passMissed).
- Song practice (`SongPracticeView.Phase`): preview → choice → countdown → learn → perform → results → loop; channels user / guide.
- Progression templates gallery, recording progressions from MIDI (`ProgressionRecordingSession`: step/free record, overdub, silence timeout).
- Chord detection: `ChordDetector.swift` + `MusicCharts.ChordIdentifier` → `IdentifiedChord {symbol, root, type, bass?}`; chord vocabulary = Tonic `ChordType` (177 cases incl. sus, add, altered 13ths) and `Interval` (52 cases P1…A15). Ranking algorithm not decompiled.
- Theory display settings: `NoteNameSystem` letters/solfege, `SolfegeSeventh` si/ti, `OctaveConvention` scientific/yamaha, `AccidentalSpelling` auto/preferSharps/preferFlats, `RomanNumeralStyle` scaleSpecific/alwaysMajor.

## 8. Compose (piano-roll composer with feedback)
`ComposeEditTool` move/cursor/paint/erase/scale; `ComposeInputMode` edit/playback/record; `SnapResolution` quarter/eighth/sixteenth; `LoopMode` section/off/full; `RecordMode` step/free. Composition lessons: `CompositionExercise {prompt, hints, template, constraints{editableBarRange?, allowedPitches?, maxBars?, editableTrackIndices?}, feedbackFocus}`. `CompositionFeedbackEngine` evaluates 13 `FeedbackFocus` metrics: contour, intervalDistribution, pitchRange, resolution, motifRepetition, sectionContrast, syncopation, rhythmicVariety, noteDensity, restUsage, registerSpread, voiceIndependence, texturalDensity → `CompositionFeedback {focus, title, observation, value?, chartData?}`. Export MIDI and MusicXML.

## 9. Input
- MIDI keyboard (CoreMIDI via MIDIKit), on-screen keyboard, computer keyboard (`useComputerKeyboard`), and microphone pitch detection (`enableMicrophoneInput`, `micAmplitudeThreshold`, `micStabilityWindowMs`, `micSilenceTimeoutMs`, `micOctaveOffset`, `micSemitoneOffset`, `micCentsOffset`, `hasCompletedMicSetup`; debounce state machine `DebounceState = detecting(note, startTime, heldNote?) | fired(note, silenceStart?) | silent`).
- Stuck-note protection: `autoClearStuckNotes`, `stuckNoteThresholdSeconds`, `showStuckNoteBanner`, `stuckNoteBannerThresholdSeconds`.
- Tuner: `TunerMode` guitar/chromatic.
