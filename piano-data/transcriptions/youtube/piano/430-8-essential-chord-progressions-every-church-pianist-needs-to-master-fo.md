## Description

In this church piano tutorial, you’re going to learn 8 essential chord progressions that show up everywhere in hymns, worship songs, and gospel music—so you can stop feeling stuck on the hymnal page and start embellishing + improvising with confidence.

I demonstrate everything in the key of C (all white notes), but the real power comes when you transpose these into the main keys you play in.

✅ What you’ll learn in this lesson:

* How chord numbers work (1, 2, 3, 4, 5, 6…)
* The difference between major vs minor chords in a key
* The “Hymn Progression” (1–4–1–5) and the common slash chord variation
* The Gospel Climb (with passing chords + #iv°7)
* Axis / Minor Axis progressions used in modern worship
* The Minor 6 Loop, Andalusian, 2–5–1, and the Turnaround (6–2–5–1)
