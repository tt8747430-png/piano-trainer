## Description

When you’re playing in church and the song leader suddenly says, “Can we do it in a lower key?”—you don’t have to freeze up. You’ll learn how to stop thinking in note names and chord letters (C, F, G, Am) and start thinking in chord numbers (1, 4, 5, 6) so you can play any hymn in any key—even if you’re reading from hymnal four-part notation. 📖 We’ll build chords from the major scale, cover the major/minor/diminished pattern in every key, and practice the most common progressions used in hymns like 1-4-1-5, 1-5-6-4, and 1-6-2-5-1. ✅
