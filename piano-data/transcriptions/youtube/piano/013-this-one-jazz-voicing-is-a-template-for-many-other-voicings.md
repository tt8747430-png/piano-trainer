## Description

This is such an important voicing for major chords - almost like a template for these quartal voicings, and quartal voicings are one of the defining elements of jazz voicings.

Do note that not every melody note allows for a nice quartal voicing.

For example, the 3rd being in the melody doesn't lend itself to a quartal voicing, at least not a full quartal voicing but definitely a partial one.

The 5th as the melody note, though, allows for a full, perfect quartal.
