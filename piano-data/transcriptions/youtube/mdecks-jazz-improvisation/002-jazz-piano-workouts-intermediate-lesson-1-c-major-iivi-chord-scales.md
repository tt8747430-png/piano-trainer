In Lesson 1 (Key of C Major) we start a focused practice system: one key per week. Instead of rushing through material, we stay in each key long enough to really absorb how it sounds, how it moves, and how it feels under the hands.

This workout is very musical and beautiful-sounding, but it’s also doing a lot of work beneath the surface. You’ll develop:
Jazz voicings
Functional harmonic progressions
Chord–scale relationships
Ear training

The Harmonic Loop (C Major)
We’re working with a looping progression:
Dm7 → G7 → Cmaj7 → A7
That final A7 (V7/ii) pulls us right back to Dm7, so you can repeat the workout continuously.

Four Dominant Colors on G7
In this lesson we explore four versions of the V chord:
G7 → G Mixolydian (optionally add the passing maj7 for a Dominant Bebop color)
G7♯5 → Whole-Tone
G7♭9 (nat 13) → Half–Whole Diminished
G7 altered (heard as a tritone sub) → D♭7♯11 with G Altered / D♭ Lydian ♭7 (same notes)

How to Practice (3 Passes)
Chords only — establish the sound of the progression
Chord-scales — connect harmony to the scale sounds inside each chord
Improvise — create lines using notes from the current chord-scale (especially over the dominant options)
Don’t worry about strict counting. This is primarily an ear-training workout: play freely and focus on hearing the voicings, tensions, and resolutions.
