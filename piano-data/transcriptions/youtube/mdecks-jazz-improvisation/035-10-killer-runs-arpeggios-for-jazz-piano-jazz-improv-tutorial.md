These runs are not only about piano technique, they are also about how to get sounds that work well in many styles of music, from Jazz to Neo Soul to just plain Improvisation. Here's the list of runs & arpeggios:
1. Using Perfect Quartals from a m7 chord (works on m7 and maj7)
2. Using two triads a tritone away (works on dominant chords)
3. Using the whole-tone scale (works on dominant chords)
4. Using a sus4 pair (works on m7 and maj7 chords)
5. Using an add9 chord arpeggio (works on m7, dominants, maj7 and altered chords)
6. Using constant structures (altered quartals) from the half-whole scale (works on dominant chords)
7. Using a perfect quartal (ascending) and adding the maj7 (desc.) (works on maj7 and m7 chords)
8. Using a perfect quartal adding the maj7 (ascending) and a perfect quartal descending (works on maj7 and m7 chords)
9. Using a m7 arpeggio + a dorian scale with the same root (works on m7 and maj7#11 chords
10. Using a sus4, doubling the octave (works on all types of chords)
