## Description

It's ok if it's musical deception 😂 

There is actually a term in music theory called a "Deceptive Cadence." This is when you set up listeners to expect a resolution to the I chord (usually with a chord progression like ii-V-I), but instead of the I, you go to some other chord (and break our trust along with it). 

Usually, this deceitful chord resolution is a vi chord, since it still shares many of the same notes as the 1 chord. In that way, it feels close to right, but "a little off." 

We took this logic to a whole new level and tested out what other chords this idea could work with. Usually, we can keep the same expected melody note on the last chord, "Bb," but change the chord underneath. The main idea is that you disrupt the listener's expectation just a little bit.
