## Description

In this worship piano tutorial, you'll learn how to make your fills sound instantly beautiful — using just 3 notes you already know.

Most pianists' fills sound plain and repetitive because they're only using basic chord tones. These 3 simple additions will transform the way your right hand sounds over any chord progression.

• The Second — the note one whole step above the root that adds color and movement
