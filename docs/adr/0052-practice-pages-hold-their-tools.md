# ADR 0052 — A Practice page holds the tools that work on its subject

- **Status:** accepted · **Date:** 2026-10-14 · **Supersedes:** ADR 0050 (a tool is a tab), ADR 0045 (Transpose's
  page) · **Amends:** ADR 0044 (Practice's groups)

## Context

ADR 0050 put each tool on a tab beside the page of its subject. The tools still were separate pages that
duplicated their subject's (Transpose's typed chords and key beside Progressions' typed line and key; the Chord
finder's naming beside Free play's), and the learner still moved between them.

## Decision

- **Free play** names the keys held or tapped as the Chord finder did: its names, the tones left out, the keys
  that hold it. The Chord finder's page goes.
- **Progressions** reads a typed line of chords in its key and plays it in any key (Transpose), and shows the
  passing chords between any two chords of its row (Passing chords). Both pages go.
- **Scales and keys**' Key view harmonises a melody note in its key (Reharmonise). Its page goes.
- **Chords** is one page with no tabs. Accompaniment lists patterns and studies, not lessons.
- Practice lists Chords, Scales and keys, Intervals, Progressions, Accompaniment; Free play; Exercises, Quiz.

## Consequences

- Lessons and Search open what a tool did on the page that now holds it.
