# Triage labels

The `Status:` line of an issue in `.scratch/` uses the skills' five role names as they are, plus `done`:

| Label             | Meaning                                 |
| ----------------- | --------------------------------------- |
| `needs-triage`    | The owner needs to evaluate it          |
| `needs-info`      | Waiting on the reporter for information |
| `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | Needs a human to implement              |
| `wontfix`         | Will not be done                        |
| `done`            | Built and checked                       |
