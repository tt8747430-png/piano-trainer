# Domain docs

One context. The glossary is [`docs/UBIQUITOUS_LANGUAGE.md`](../UBIQUITOUS_LANGUAGE.md) (read it as `CONTEXT.md`);
decisions are in [`docs/adr/`](../adr), indexed in its README.

- **Before exploring,** read the glossary and the ADRs that touch the area, and the feature's spec in `.scratch/` if
  there is one.
- **Use the glossary's words** in issue titles, proposals and test names, never a synonym it lists under "Avoid". A
  concept it lacks is either invented (reconsider) or a gap (add it with `domain-modeling`).
- **Flag ADR conflicts.** If output contradicts an ADR, say so and why it is worth reopening; never override it
  silently.
