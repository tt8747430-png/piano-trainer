# Ubiquitous Language

Canonical terms for code, UI copy, commits and discussion. Code uses the **Term**; where the interface says it
differently, the UI column says how.

## Content

| Term            | Means                                                                                                                                                         | UI                         | Avoid                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | --------------------------------- |
| **Piece**       | Anything that opens in the Player: a song, a study or a progression (`kind`)                                                                                  | Song / Study / Progression | item, track, tune                 |
| **Study**       | A Piece written to practise a technique: the method books' lesson pieces (Called to Play)                                                                     | Study («Этюд»)             | exercise (that is Practice's)     |
| **Exercise**    | A line of notes generated from a rule in any key, practised in Practice: the Chromatic walk; later a scale from any note, Barry Harris's 6th-diminished scale | Exercise («Упражнение»)    | drill, study (a Study is a Piece) |
| **Listing**     | A songbook entry with no chart yet; shown in Songs, never opened in the Player                                                                                | Song, "no chart yet"       | stub, placeholder                 |
| **Collection**  | An ordered group of Pieces and Listings from one source («Боже, спасибо», Called to Play…)                                                                    | Collection                 | book, category                    |
| **Book**        | A printed songbook or method that a Source cites; not a Collection                                                                                            | the book's title           | collection                        |
| **Source**      | Where a Piece is printed: its Book, number and page                                                                                                           | Source                     | origin, reference                 |
| **Credit**      | A role (words, music, harmony…) and the names printed for it                                                                                                  | "Words: …", "Music: …"     | author string, by                 |
| **Chart**       | A song's or study's chords by section, line and bar, in the chart format                                                                                      | Chords                     | sheet, score, lead sheet          |
| **Progression** | A Piece written as degrees + functions, in one line or in a Chart's Sections, whose chords grow with the chosen Chord size                                    | Progression                | chord flow, sequence              |
| **Section**     | A labelled part of a Chart or of a sectioned Progression: intro, verse, chorus, ending, practice, hymn, part                                                  | Verse, Chorus, …           | block, segment                    |
| **Bar**         | One measure of a Chart                                                                                                                                        | Bar                        | measure (in code), segment        |
| **Method code** | A per-chord playing technique from the source book (`:t1`, `:3ch`)                                                                                            | —                          | style code                        |
| **LocalText**   | Content text in both languages, `{ en, ru }`                                                                                                                  | —                          | translation, i18n string          |

## Music

| Term                       | Means                                                                                                                                                                                                                        | Avoid                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| **Pitch class**            | One of the 12 notes, whatever the octave (0–11)                                                                                                                                                                              | note number                                       |
| **Spelled note**           | A note with its letter and accidental (E♭, not D♯)                                                                                                                                                                           | note-name string                                  |
| **Chord quality**          | The kind of chord the table names: `maj`, `m7`, `hd`, … (36)                                                                                                                                                                 | chord type (in code)                              |
| **Chord family**           | A group of qualities: triads; 6th & add; 7ths; 9ths & more; altered 7ths                                                                                                                                                     | chord group                                       |
| **Chord symbol**           | The written name, `F#m7b5/C`                                                                                                                                                                                                 | chord name                                        |
| **Interval** (reference)   | A distance between two notes named and heard: its short name (m3), semitones and whole tones, consonance, written on one staff and played Up, Down and Together; the Intervals reference's card                              | distance, step                                    |
| **Consonance**             | How an interval sounds, by its simple interval: perfect (unison, 4th, 5th, octave), imperfect (3rds, 6ths) or a dissonance (2nds, 7ths, augmented and diminished)                                                            | harmony                                           |
| **Available tension**      | A note over a 7th chord that colours it (`tensions.ts`); with the chord tones, **Weak** (the root, a perfect 5th) and **Strong** (the 3rd or suspension, the 7th), and the Avoid notes, the four groups of the owner's table | extension (a built chord's), option (in code)     |
| **Avoid note**             | A note over a chord that clashes with one of its tones, named by the degree its semitones make (the 11 over a major 3rd)                                                                                                     | wrong note                                        |
| **Chord tone**             | One note of a chord, with its **Role** (root, 3rd, 5th, 7th, 9th, 11th, 13th) and **Degree** label (`♭3`)                                                                                                                    | chord note                                        |
| **Tone**                   | A spelled note measured from a root, with its Role and Degree label: a Chord tone, or one note of a scale                                                                                                                    | scale note                                        |
| **Key**                    | A tonic, major or minor (G major, G♯ minor); a song is written in one. Its major or minor is not a Mode                                                                                                                      | tonality (in code), mode                          |
| **Transpose**              | Move to another tonic by the interval between tonics, letters kept                                                                                                                                                           | shift                                             |
| **Chord size**             | How much of each chord a Progression plays: triads, sevenths or ninths; in the Chords reference a built chord's highest number (Triad · 7th · 9th · 11th · 13th); in Chords view how many notes a Scale chord stacks         | voicing (that is the notes' layout), colour       |
| **Voicing**                | How a chord's notes are laid out under the hands: shell, rootless, drop 2, quartal, upper structure                                                                                                                          | chord size, shape                                 |
| **Inversion**              | Which chord tone is lowest                                                                                                                                                                                                   | position                                          |
| **Placed tone**            | A Tone at a key on the keyboard, as the explorers and the quiz place chords and scales (`placeChord`, `placeScale`)                                                                                                          | voicing (a Voicing is a layout type)              |
| **Scale gap**              | The step between neighbouring notes of a scale: W, H or W+H (Т, П, Т+П in Russian)                                                                                                                                           | step (a Step is on the Path)                      |
| **Scale kind**             | Thirteen, in three families: major and minor (major; natural, harmonic, melodic minor), the Modes, pentatonic and blues (major and minor pentatonic, major and minor blues; the minor blues' id is `blues`)                  | scale type                                        |
| **Mode**                   | A church mode: Dorian, Phrygian, Lydian, Mixolydian or Locrian, a Scale kind (Ionian is major, Aeolian natural minor)                                                                                                        | key (a Key is major or minor)                     |
| **Parent scale**           | The major scale a Mode is a mode of (D Dorian's is C major); a mode is written in its parent's key                                                                                                                           | relative (that is major ↔ minor)                  |
| **Scale chord**            | A scale's notes stacked in thirds from a degree: 3 a triad … 7 a 13th, named by one rule (`stackSuffix`, `Maj9#11`); not a Chord quality, though it may be one                                                               | diatonic chord, chord quality                     |
| **Figures**                | An inversion's figured-bass mark after a numeral: ⁶, ⁶₄ for a triad; ⁷, ⁶₅, ⁴₃, ⁴₂ for a 7th; none from a 9th up                                                                                                             | inversion symbol                                  |
| **Borrowed chord**         | A chord of a parallel scale on a key's degree (modal mixture): a major key's iv, ♭III, ♭VI, ♭VII; a minor key's V, IV, the Picardy I and the Neapolitan ♭II                                                                  | chromatic chord, secondary                        |
| **Circle of fifths**       | The 24 keys on two rings, majors outside and their relative minors inside, a fifth apart round the circle; the Keys reference's chooser                                                                                      | wheel                                             |
| **Chord parts**            | A chord as the Chords reference builds it: Triad, Chord size, 7th, Added tone, Alterations (`ChordParts`); only what the chord takes is offered                                                                              | chord options, quality (a Quality is the table's) |
| **Triad** (a chord part)   | The builder's base: major, minor, diminished, augmented, suspended 2nd or 4th (a suspension is a triad)                                                                                                                      | quality, sus option                               |
| **Added tone**             | A tone a triad adds: 6, 6/9, add2, add4, add9, add11                                                                                                                                                                         | extension (that is a 7th chord's)                 |
| **Alteration**             | A raised or lowered tone of a 7th chord with a major 3rd: a dominant's ♭5, ♭9, #9, #11, ♭13 (its available tensions), a major 7th's #11                                                                                      | altered extension, tension (in code)              |
| **Degree** (progression)   | A Roman numeral from the tonic on the major scale (`ii`, `♭VII`)                                                                                                                                                             | step                                              |
| **Function** (progression) | How a degree's chord grows with the Chord size: `maj`, `min`, `dom`, `domb9`, `hd`, or fixed `=quality`                                                                                                                      | chord role                                        |

## Practice

| Term                   | Means                                                                                                                                                                                                                                                                                  | Avoid                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **Pattern**            | A named accompaniment style for the right and left hand                                                                                                                                                                                                                                | rhythm, style (in code)                   |
| **Figure**             | One hand's part of a Pattern: fixed events, or a right hand playing the tune                                                                                                                                                                                                           | part, RHP/LHP                             |
| **Practice toggle**    | One of the Setup's saved switches: finger numbers, named notes, melody, metronome, count-in, recording                                                                                                                                                                                 | option, flag                              |
| **Performance**        | What the Player plays: bars, beat groups, chord symbols and notes on a timeline, each note with its written onset, Roll and spelling; `arrange` makes one from a Piece                                                                                                                 | playback, song data                       |
| **Tick**               | The domain's unit of time: 12 per beat                                                                                                                                                                                                                                                 | step (as time)                            |
| **Beat group**         | Notes sharing an onset (a rolled chord is one): what ‹ › step through and Wait mode waits on                                                                                                                                                                                           | chord (as time), group                    |
| **Pass**               | One play-through of the passage (the Loop, or the whole piece), the first from the Cursor; Listen queues passes, each at its own tempo under Speed training                                                                                                                            | run, cycle                                |
| **Transport**          | Listen's playback: passes queued ahead of the audio clock and followed as they sound                                                                                                                                                                                                   | player loop, engine                       |
| **Listen / Wait mode** | How the Player goes, chosen in the tempo popover: the app plays at a tempo (50%, 75%, 100% or any) / the app waits for your notes. ‹ › step through beat groups in either; Step is no longer a mode                                                                                    | auto, manual, Your turn, Step mode        |
| **Setup**              | The Player's sheet (⚙): the Piece's own choices (key, pattern, the hands' figures, chord size, melody), then how it plays (swing, finger numbers, named notes, metronome, count-in). The tempo and hands are the toolbar's popovers (Russian UI: «Параметры»; «Настройки» is Settings) | options, settings                         |
| **Start on**           | The degree a scale's run starts from, 1 the tonic: the run goes from it up an octave and back                                                                                                                                                                                          | start note, rotation                      |
| **Fingering**          | How a run is fingered: **From the thumb** (the thumb on the starting note) or **As the scale** (each note keeps its Continuing finger)                                                                                                                                                 | fingers (that is the finger row's choice) |
| **Continuing finger**  | A note's finger in a longer run of its scale: one more for each degree it lies past the thumb before it                                                                                                                                                                                | scale finger                              |
| **Walk the chords**    | A scale's chords from the tonic up to its octave and back, a chord a bar; in place in Chords view, or in the Player (`/play/walk`) with a song's patterns                                                                                                                              | chord ladder, diatonic run                |
| **Chromatic walk**     | Chosen chord qualities root by root, a semitone at a time, from a root up to its octave, down, or up and back (the octave once); in the Player (`/play/chromatic`) with a song's patterns; no key, so nothing plays the key's triads («По полутонам»)                                  | chromatic run, chord drill                |
| **Score**              | Music as it is written (`shared/lib/notation`): measures on a grand staff, one or two voices a staff, note values, ties, accidentals, chord symbols; `notate` writes one from a Performance and it is never played                                                                     | notation (the kernel), sheet              |
| **Sheet music**        | The Player's staff: the Score engraved in one line that scrolls sideways (`SheetMusic`, `ScoreView`), chord symbols over numbered bars, the Cursor and the Loop                                                                                                                        | score view, tab, the Setup sheet          |
| **Cursor**             | The sky-mist band on the sheet music behind the beat group now; the sheet scrolls to keep it in sight                                                                                                                                                                                  | playhead, marker                          |
| **Loop**               | Bars the Player goes round (`loop=3-6` in the URL, bars as printed): Listen plays passes of it, ‹ › and Wait mode stay inside it; its grips drag over bars                                                                                                                             | repeat, section, A–B                      |
| **Recording**          | A performance shipped with a piece (a singer's), played along in Listen in the piece's own key, at any tempo with its pitch kept, from each pass's first bar («Запись»); not the planned record from a MIDI keyboard, which writes a score                                             | track, audio, backing                     |
| **Speed training**     | Listen below the piece's tempo, each pass 5% of it faster (1 BPM at least), up to it                                                                                                                                                                                                   | ramp, accelerate                          |
| **Swing**              | Off-beat 8ths played long-short (at two thirds of the beat), simple meters only; the sheet music stays straight                                                                                                                                                                        | shuffle                                   |
| **Roll**               | How late a rolled chord's note sounds after the chord's onset (ticks); the chord is written once, with a wavy line                                                                                                                                                                     | arpeggio (a played figure), strum         |
| **Live keyboard**      | The keyboard every screen shows (`LiveKeyboard`): the whole piano, scrolling; a tapped key sounds; a key goes down while it sounds                                                                                                                                                     | static keyboard, piano roll               |
| **Down** (a key)       | A key the app sounds now (under Spotlight, struck last), or one a hand holds: a finger, a typed key, a MIDI keyboard, for at least the **shortest press**; drawn pressed, in its mark's full colour (a plain key in sky). Name chord's shown chord is **lit**, not down                | active, playing                           |
| **Wash** (a mark's)    | The pale colour a marked key wears while it is quiet; it turns the mark's full colour when the key goes down                                                                                                                                                                           | tint, light, dimmed                       |
| **Shortest press**     | The least time a key a hand plays stays down (150 ms), so a tap as light as a trackpad's shows                                                                                                                                                                                         | debounce, minimum                         |
| **Scroll** (swipe)     | The keyboard's default swipe: a key sounds the moment it is touched and the keys hold still under the finger; only that key sounds. The keyboard scrolls from its Rail                                                                                                                 | pan mode                                  |
| **Glissando** (swipe)  | The other swipe: every key a finger slides onto sounds, once per entry                                                                                                                                                                                                                 | slide mode, glide                         |
| **Rail**               | The dark fascia the keys hang from, the piano's length: a swipe on it scrolls the keys; it holds ‹ ›, the Keyboard map and the settings button (`RailButton`)                                                                                                                          | toolbar, header                           |
| **Keyboard map**       | The Rail's strip of all 88 keys, framing the part in view; a slider named "Keys in view"                                                                                                                                                                                               | minimap, overview                         |
| **Keyboard settings**  | Keys, Swipe, Note names, Keyboard map, Play from the computer keyboard: saved for every keyboard (`KeyboardSettings`)                                                                                                                                                                  | keyboard prefs, options                   |
| **Key size**           | How wide the white keys are: Fit (the range fills the width) · Large · Whole piano (`KeySize`)                                                                                                                                                                                         | zoom, scale                               |
| **Note names**         | Which keys carry their note's name: C (every C) · All · None (`NamedKeys`); a mark's own label wins                                                                                                                                                                                    | labels (alone)                            |
| **Named notes**        | The Setup's switch that writes each note's name in its head on the Player's staff, as spelled (F♯ in D major though the signature carries the sharp): Bravura's note name noteheads; a double sharp or flat keeps a plain head                                                         | note names (the keys'), labels            |
| **Typing keys**        | The computer keyboard as a piano, read by physical key: A to ' play, the row above the black keys, Z X the octave                                                                                                                                                                      | hotkeys, shortcuts                        |
| **Spotlight**          | On the references', a lesson's and a Piece's keyboards: the keys the app puts down are the ones **struck** last, every mark kept                                                                                                                                                       | highlight, focus, dim                     |
| **Struck** (keys)      | The sounding keys struck last: a block chord's together, an arpeggio's or a run's one by one (`struck()`)                                                                                                                                                                              | active, current                           |
| **Finger row**         | The fingers in circles under the keys, a black key's above a white key's                                                                                                                                                                                                               | finger labels                             |

## Path and progress

| Term         | Means                                                                                      | Avoid                     |
| ------------ | ------------------------------------------------------------------------------------------ | ------------------------- |
| **Level**    | 1 Beginner · 2 Elementary · 3 Intermediate · 4 Advanced: a Step's place on the Path        | difficulty, grade         |
| **Path**     | Every Step in order, level by level; the one source of levels                              | course, curriculum        |
| **Step**     | One entry on the Path: a Piece, a chord family or a scale kind (`piece:bz5`, `chords:sev`) | lesson, item, task        |
| **Learned**  | A Step the learner marked, or a chord or scale Step marked once every Skill in it is Known | done, completed, mastered |
| **Continue** | The one suggestion on the Path screen: what to do next                                     | resume, next up           |

## Theory gaps

| Term                      | Means                                                                                                                                 | Avoid               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| **Skill**                 | Something rated from quiz answers: one chord quality or one scale kind (`chord:m7`)                                                   | ability, topic      |
| **Evidence**              | The last 5 quiz answers on a Skill                                                                                                    | history, attempts   |
| **Known / Gap / Unknown** | A Skill's rating: 4 of the last 5 right including the latest / tried, not known / never tried                                         | mastered, weak, new |
| **Check**                 | A short quiz scoped to some Skills (a Piece's chords, a Step's family)                                                                | test, exam          |
| **Build chord**           | The quiz mode that names a chord for the learner to play                                                                              | exercise, drill     |
| **Name chord**            | The quiz mode that plays a chord for the learner to name                                                                              | exercise, drill     |
| **Build scale**           | The quiz mode that names a scale for the learner to play                                                                              | exercise, drill     |
| **My gaps**               | The quiz scope that asks Gap Skills first, then Unknown Skills from Pieces the learner opened                                         | review, weak spots  |
| **Theory quiz**           | One of Practice's open-ended quizzes: Build chord, Name chord or Build scale over the chosen Skills, or My gaps; a Check is bounded   | tab, mode           |
| **Explorer**              | A Reference that places any chord or scale on any root on the keyboard: Learn → Chords (a chord built from its Chord parts) or Scales | viewer, browser     |

## Places and screens

| Term                         | Means                                                                                                                                                                                                | UI                           | Avoid                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ------------------------------ |
| **Place**                    | One of the four top-level sections in the nav: Path · Songs · Learn · Practice                                                                                                                       | Path, Songs, Learn, Practice | tab (for a place), section     |
| **Learn**                    | The place of lessons and references: Chords, Scales, Keys, Intervals, Available tensions (later tools)                                                                                               | Learn («Обучение»)           | Theory                         |
| **Practice**                 | The place of the Theory quiz, studies and progressions (later exercises and trainers)                                                                                                                | Practice («Практика»)        | Drill, Train                   |
| **Lesson**                   | A Learn page that teaches music, with examples that play (`entities/lesson`, content as code)                                                                                                        | Lesson («Урок»)              | tutorial, article              |
| **Reference**                | A Learn page to look things up in: Chords, Scales, Keys, Intervals, Available tensions                                                                                                               | Reference («Справочник»)     | tool, dictionary               |
| **Keys** (the reference)     | A page for each of the 24 keys, chosen on the Circle of fifths: its signature, notes, relative, modes, chords, Borrowed chords and songs (`/learn/keys?key=Eb`)                                      | Keys («Тональности»)         | key signature page             |
| **Shelf**                    | Where a piece's page is: a song or listing on Songs, a study or progression on Practice (`PieceLink`)                                                                                                | —                            | category                       |
| **Scale view / Chords view** | The Scales reference's two views: the run from its Start on note, fingered, on the keys and the staff; or each degree's Scale chord on its key, in a size (triads to 13ths) and an inversion, walked | Scale · Chords               | mode (a Mode is a church mode) |
| **Keys play**                | In Chords view, what a degree's key plays: its chord, or its own note (lighting the chords that hold it)                                                                                             | Keys play: Chords · Notes    | tap mode                       |
| **Holds** (a chord, a note)  | A chord holds a note when the note is one of its notes, in any octave (`chordHolds`)                                                                                                                 | "E is in C, Em and Am"       | contains, fits                 |
| **Pop-up button**            | A button that shows its label and current value and opens a list to choose one of many (`Dropdown` in code); Apple's pop-up button. One that checks several of many is `MultiDropdown` (Alterations) | —                            | select, chips                  |
